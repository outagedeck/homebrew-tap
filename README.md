# OutageDeck Homebrew tap

Install the [OutageDeck CLI](https://github.com/outagedeck/cli):

```bash
brew install outagedeck/tap/outagedeck
```

Then check one or more cloud or SaaS providers:

```bash
outagedeck status aws cloudflare github openai
```

See [outagedeck/cli](https://github.com/outagedeck/cli) for JSON output, CI exit codes, provider search, and release archives.
